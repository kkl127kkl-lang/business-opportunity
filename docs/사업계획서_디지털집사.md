## 1. Executive Summary

### 한 줄 요약

> 스마트폰과 키오스크가 어려운 5060세대를 위해, AI 상담원과 인간 상담원이 함께 디지털 문제를 즉시 해결해주는 월 구독 서비스

### 왜 지금인가?

| 요인 | 데이터 |
|------|--------|
| 한국 초고령사회 공식 진입 | 2025년, 65세 이상 1,084만 명 (21.2%) |
| 키오스크 3년간 2.4배 폭증 | 2019년 19만 대 → 2022년 45만 대 |
| 디지털포용법 시행 | 2026년 1월 22일 시행 예정 |
| 고령층 디지털 역량 최하위 | 일반 국민 대비 71.4% (4대 취약계층 중 꼴찌) |
| 직접 경쟁자 거의 없음 | 기존 대안은 모두 "가르치는" 방식 (해결 안 됨) |

### 핵심 지표

| 항목 | 수치 |
|------|------|
| 타겟 시장 | 50세 이상 약 2,300만 명 |
| 월 구독료 | 19,900원 ~ 49,900원 |
| 초기 자본 | 100만원 미만으로 MVP 시작 가능 |
| AI 처리율 목표 | 70~85% (인간 상담원 에스컬레이션 15~30%) |
| 손익분기 | 구독자 300명 시점 (약 6~9개월) |

## 3. 고객 분석

### 3-1. 실제 고객 목소리 (393건 댓글 분석)

참고 사이트에서 수집된 393건의 실제 고객 목소리를 카테고리별로 분석한 결과:

| 카테고리 | 건수 | 비중 | 핵심 감정 |
|---------|------|------|----------|
| 금융/은행 서비스 어려움 | 167건 | 42% | 불안, 포기 |
| 키오스크 사용 어려움 | 88건 | 22% | 창피함, 눈치 |
| 스마트폰/앱 활용 | 84건 | 21% | 좌절, 답답함 |
| 보이스피싱 피해/불안 | 67건 | 17% | 공포, 불신 |
| 심리적 소외감 | 48건 | 12% | 체념, 자괴감 |

#### 실제 고객 증언

> "키오스크 앞에서 버벅여서 뒷사람 기다리는 게 눈치 보인다." — 문화센터 학습자

> "전기차 충전이 앱으로 돼 있네요. 아버지가 가끔 타실 텐데 빡실 것 같습니다." — 클리앙 사용자

> "단독주택이라 '충전' 버튼만 누르면 되는데 부모님이 못 하셔서 제가 매일 눌러드립니다." — 클리앙 사용자

> "스마트폰 건드리면 사건 발생할까봐 안 써요." — 보이스피싱 불안 시니어

> "나는 몰라도 돼" — 체념한 시니어 (사회적 고립 심화)

### 3-2. 고객 유형 분류 (4가지 페르소나)

#### 유형 A — "눈치형" (약 40%, 가장 많음)

| 항목 | 내용 |
|------|------|
| 대표 발언 | "키오스크 앞에서 버벅거리면 뒷줄 사람들 눈치 보여서…" |
| 실력 수준 | 방법은 어느 정도 알지만 실수할까 봐 두려움 |
| 핵심 감정 | **창피함 + 불안** |
| 트리거 | 새 메뉴, 새 UI, 업데이트될 때마다 처음부터 막힘 |
| 원하는 것 | 실수 없이, 남 눈치 보지 않고 해결 |
| 적합 서비스 | **1단계: 대신 해줄게** → 점차 2단계로 이동 |
| 근거 | 키오스크 불편 88건 중 "뒷사람 눈치" 49.0% |

#### 유형 B — "귀찮음형" (약 25%)

| 항목 | 내용 |
|------|------|
| 대표 발언 | "할 줄은 아는데, 회원가입하고 카드 등록하고… 그게 다 귀찮아" |
| 실력 수준 | 50대 초반, 디지털 어느 정도 가능 |
| 핵심 감정 | **번거로움** |
| 트리거 | 새 앱 설치, 본인인증, 카드 등록 단계 |
| 원하는 것 | 누가 세팅만 대신해줬으면 |
| 적합 서비스 | **1단계: 대신 해줄게** (세팅 대행) |
| 근거 | 키오스크 불편 중 "복잡한 단계" 51.4% |

#### 유형 C — "진짜 모름형" (약 20%)

| 항목 | 내용 |
|------|------|
| 대표 발언 | "스마트폰을 배우긴 했는데, 앱마다 다 달라서 매번 모르겠어" |
| 실력 수준 | 자녀에게 반복해서 물어보기 미안 |
| 핵심 감정 | **학습 포기 + 자괴감** |
| 트리거 | 앱마다 UI가 달라서 배워도 소용없다고 느낌 |
| 원하는 것 | 내가 직접 할 수 있게 되고 싶다 (자존감 회복) |
| 적합 서비스 | **2단계: 같이 할게** → 3단계로 성장 |
| 근거 | 디지털 역량 수준 65.6%, 심리 소외감 48건 |

#### 유형 D — "보안 불안형" (약 15%)

| 항목 | 내용 |
|------|------|
| 대표 발언 | "개인정보 넣었다가 보이스피싱 당할까봐… 그냥 안 써" |
| 실력 수준 | 할 수 있지만 안 하는 사람 |
| 핵심 감정 | **불신 + 공포** |
| 트리거 | 보이스피싱 뉴스, 주변 피해 사례 |
| 원하는 것 | 믿을 수 있는 사람이 옆에서 같이 해줬으면 |
| 적합 서비스 | **2단계: 같이 할게** (신뢰 형성 후 1단계) |
| 근거 | 보이스피싱 불안 67건, 고령층 피해액 20대의 3배 |

### 3-3. 왜 이 문제가 아직 해결되지 않았는가?

| 원인 | 상세 설명 | 근거 데이터 |
|------|----------|------------|
| **1. "가르치는 것"과 "해결하는 것"의 혼동** | 모든 기존 서비스가 "가르쳐 드릴게요". 고객이 원하는 건 "대신 해줘" | 구청 교육은 1회성, 유튜브 강의는 혼자 못 봄 |
| **2. 대기업의 시니어 시장 무시** | "돈 안 되는 시장"이라는 편견 | 50대 자산 6.1억, 60대 소비증가율 63.1% |
| **3. 수요자가 직접 검색을 못 함** | 디지털 서비스가 필요한 사람이 디지털로 그 서비스를 찾을 수 없는 역설 | 80세+ 인터넷 이용률 49.1% |
| **4. 신뢰 장벽** | "모르는 사람에게 내 폰을 맡긴다고?" | 보이스피싱 불안 67건 |
| **5. 기존 대안의 불완전성** | SK 시니어폰(기능 제한만), KT 디지털배움터(교육만, 예산 60% 삭감) | 디지털배움터 예산 698억→279억 |

## 4. 서비스 설계

### 4-1. 서비스 개념

> **서비스명**: 디지털 집사 (Digital Butler)
> **한 줄 정의**: 5060세대의 모든 디지털 문제를 즉시 해결하는 24시간 AI+인간 하이브리드 도우미

**핵심 원칙**: "가르치는 서비스"가 아니라 "해결하는 서비스"
— 단, 해결하면서 자연스럽게 배우게 되는 구조

### 4-2. 서비스 3단계 구조

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  [3단계] 배워볼래?  (Teach Me)                        │
│   └ 맞춤형 1분 영상, 월간 성취 리포트                    │
│                                                     │
│  [2단계] 같이 할게   (Do It With Me)                   │
│   └ 화면 공유 실시간 안내, 옆에서 같이                    │
│                                                     │
│  [1단계] 대신 해줄게  (Do It For Me)    ← 대부분 여기    │
│   └ 카톡/전화 한 마디면 즉시 해결                        │
│                                                     │
└─────────────────────────────────────────────────────┘
고객이 1단계에서 시작 → 자연스럽게 3단계로 성장
1단계에만 머물러도 전혀 문제없음 (= 구독 유지의 핵심)
```

### 4-3. 서비스 상세 설계

#### 1단계 — 대신 해줄게 (Do It For Me)

**대상 고객**: 유형 A(눈치형), B(귀찮음형), D(보안불안형)
**이용 채널**: 카카오톡 채널 / 전화(080 무료) / 가족 대리 요청

| 서비스 영역 | 대행 가능 업무 |
|------------|---------------|
| 음식 주문 | 맥도날드·배달의민족·요기요 등 키오스크/앱 주문 대행 |
| 교통/예매 | KTX·항공권·고속버스 예매, 택시 호출 |
| 병원/건강 | 병원 앱 예약, 진료 접수, 처방전 확인 |
| 금융 | 공과금 납부 안내, 보험금 청구 절차 안내, 계좌 조회 안내 |
| 관공서 | 민원24 서류 발급, 주민센터 예약 |
| 쇼핑 | 쿠팡·마켓컬리 주문, 반품/교환 접수 |
| 생활 | 앱 설치/삭제, 와이파이 연결, 프린터 설정, 전기차 충전 |
| 보안 | 보이스피싱 의심 문자/전화 확인, 스팸 차단 설정 |

**작동 흐름**:
```
고객: (카톡) "맥도날드 빅맥세트 포장 주문해줘"
AI 집사: "네, 어느 매장이세요? 강남역점으로 할까요?"
고객: "응 거기"
AI 집사: "빅맥세트 포장 주문 완료! 픽업번호 23번이에요. 15분 후에 가시면 됩니다."
```

#### 2단계 — 같이 할게 (Do It With Me)

**대상 고객**: 유형 C(진짜 모름형), D(보안불안형)
**이용 채널**: 화면 공유(TeamViewer QuickSupport) / 영상통화

| 서비스 영역 | 안내 방식 |
|------------|----------|

### 5-1. AI + 인간 하이브리드 상담 모델

```

         │

  │  (1차 처리)   │

  │  처리 가능:   │  70~85% 자동 해결
  │  - 단순 주문  │
  │  - 정보 안내  │
  │  - 예약 대행  │
  │  - FAQ 응답   │
  └──────┬───────┘
         │
    해결 불가 / 고객 불안 감지 시
         │
         ▼
  ┌──────────────┐
  │  인간 상담원   │  ← 15~30% 에스컬레이션
  │  (2차 처리)   │
  │              │

  │  - 복잡한 대행 │

  └──────────────┘
```

**Klarna 교훈 반영**: Klarna는 AI만으로 700명 상담원을 대체했다가, 품질 저하로 인간 상담원을 재고용함. **AI만으로는 부족하고, 인간 선택권이 반드시 필요**.

### 5-3. AI vs 인간 비용 비교

| 구분 | AI 상담원 | 인간 상담원 |
|------|----------|-----------|
| 1건당 비용 | **420~700원** | **1,000~1,500원** |
| 운영 시간 | **24시간/365일** | 주 40시간 (교대 시 추가 인력) |
| 월 고정비 (1,000건 기준) | **42~70만원** | **100~150만원** |
| 확장성 | 무제한 | 인력 채용 필요 |
| 감정 케어 | 제한적 | 우수 |
| 보안 업무 | 불가 (규제) | 가능 |

**하이브리드 모델 목표**:
- AI 처리율: **70~85%**
- 인간 에스컬레이션: **15~30%**
- 응답 시간: AI 즉시(3초), 인간 2분 이내
- 고객 만족도: **85%+** (업계 벤치마크)

## 결론

### 이 사업의 본질

> **"기술 지원"을 파는 것이 아니라 "존엄성"을 파는 것**

- 키오스크 앞에서 창피당하지 않을 권리
- 자녀에게 매번 부탁하지 않아도 되는 자립심
- 세상 변화에 뒤처지지 않는다는 안심감
- 보이스피싱에 당하지 않을 안전함

### 왜 이 사업이 성공하는가?

1. **고통이 진짜다** — 393건의 실제 목소리, 10개 중 6개 만점
2. **돈이 된다** — 50대 자산 6.1억, 60대 소비증가 63%, 구독 지불 의향 검증
3. **경쟁이 없다** — "해결"해주는 서비스가 전무, "가르치는" 서비스만 존재
4. **시작이 쉽다** — 카톡 채널 + 전화 1개, 내일 당장 시작 가능
5. **이탈이 어렵다** — 한번 의존하면 못 끊는 구조, 가족 연결로 이중 락인
6. **정책이 밀어준다** — 디지털포용법 시행, 정부/기업이 이 서비스를 필요로 함
7. **글로벌로 간다** — 전 세계 고령화, 일본 101조 엔 시장, AARP $945억 소비
