## B-2. 단계별 개발 구현 계획

```
====================================
1차 개발 — 핵심 동작 (MVP)
"고객이 카톡으로 요청하면 AI가 해결하고, 자녀가 구독 선물할 수 있다"
====================================

목표: 시니어가 카톡 한 줄로 디지털 문제를 해결받고, 자녀가 부모님 구독을 선물할 수 있는 상태

만들 것:

[카카오톡 AI 집사 — 시니어 메인 채널]
1. 카카오톡 채널 챗봇 (Claude API 연동)
   - 자연어 대화로 요청 접수 ("맥도날드 빅맥 주문해줘")
   - AI가 직접 처리 가능한 요청: 즉시 해결 + 결과 안내
   - AI가 못 하는 요청: "상담원 연결할게요" → 인간 에스컬레이션
   - 대화 기억 기능 (네이버 케어콜 벤치마크: "지난번에 KTX 예매하셨잖아요")
   - 보이스피싱 의심 문자/링크 판별 기능

2. 인간 상담원 대시보드 (관리자 웹)
   - AI가 에스컬레이션한 요청 목록 (실시간)
   - 고객 대화 히스토리 확인
   - 상담원이 카톡 채널을 통해 고객에게 직접 응답
   - 화면 공유 원격 지원 (TeamViewer QuickSupport 연동)
   - 요청 유형/처리 시간/만족도 통계

3. 가족 웹앱 (PWA)
   - 가입/로그인 (카카오 소셜 로그인)
   - 부모님 구독 선물 결제 (카카오페이 + 카드)
   - 부모님 활동 요약 (건수만 표시, 내용은 비공개)
     예: "이번 주 엄마가 3번 도움받으셨어요"
   - 부모님 성취 알림 푸시
     예: "엄마가 오늘 처음으로 KTX 예매를 혼자 하셨어요!"
   - 긴급 알림 (보이스피싱 의심 시 자녀에게 즉시 알림)
   - 구독 관리 (플랜 변경, 결제 내역, 해지)

4. 구독/결제 시스템
   - 3개 구독 플랜: 라이트(19,900원) / 스탠다드(34,900원) / 패밀리(49,900원)
   - 충전제: 10,000원 선불 충전 → 건당 차감 (구독 부담 없는 진입 옵션)
   - 카카오페이 + 카드 결제 (토스페이먼츠 PG 연동)
   - 자녀→부모 선물 구독 흐름
   - 7일 무료 체험 → 자동 전환 (해지 언제든 가능)
   - 월/연 결제 선택

5. 서비스 랜딩 페이지
   - 서비스 소개 + 고객 후기 + 요금제 + 가입 CTA
   - 시니어용: 카톡 채널 추가 QR코드 + 전화번호
   - 자녀용: "부모님께 선물하기" 버튼
   - SEO 최적화 (시니어 디지털 도우미 관련 키워드)

⛔ 1차에서 안 하는 것:
   - 전화(음성) AI 상담 — 2차에서 구현
   - PWA 시니어 전용 앱 — 2차에서 구현
   - O2O 방문 케어 — 3차에서 구현
   - 다국어 지원 — 3차 이후
   - 네이티브 앱 (iOS/Android) — 당분간 불필요
   - 커뮤니티 기능 — 3차 이후
   - B2B 기업 복지 대시보드 — 3차에서 구현

💬 코멘트:
   카카오톡은 시니어 도달률 97%로 앱 설치가 불필요한 유일한 채널.
   가족 웹앱은 "자녀가 결제자"라는 핵심 가설을 검증하기 위해 1차에 포함.
   Papa의 교훈 — "시니어에게 직접 과금하지 말고 제3자가 내게 하라".
   충전제(10,000원)는 구독 부담 없이 서비스를 체험할 수 있는 최저 진입점.
   이 두 가지가 되면 핵심 비즈니스 모델이 검증됨.


====================================
2차 개발 — 채널 확장 + 사용성 개선
"전화로도 되고, 웹앱으로도 되고, 더 똑똑해진다"
====================================

목표: 카톡 외 전화/웹 채널 추가, AI 음성 상담, 시니어 전용 PWA 앱

만들 것:
1. AI 음성 상담 (전화)
   - 080 수신자부담 전화번호
   - AI가 전화 받아서 자연어로 대화 (Retell AI 또는 네이버 CLOVA)
   - 복잡한 요청은 인간 상담원으로 자동 전환
   - 대화 내용 자동 텍스트 변환 → 상담원 대시보드에 표시
   - 벤치마크: Candoo Tech "전화 먼저, 기술은 나중"

2. 시니어 PWA 웹앱 ("편한 화면")
   - 홈 화면 추가만으로 앱처럼 사용
   - 큰 글씨 + 큰 버튼 (유니버설 디자인, 토스 벤치마크)
   - "시니어 모드"라 부르지 않음 (카카오뱅크 "간편홈" 벤치마크)
   - 주요 기능 바로가기: 도움 요청 / 내 기록 / 배운 것
   - 오프라인에서도 기본 정보 확인 가능 (Service Worker 캐싱)

3. 디지털 교실 (학습 콘텐츠)
   - 맞춤형 1분 영상 가이드 (내 폰 화면 기준)
   - 앱별 사용법: 배달의민족, 카카오페이, 네이버지도, KTX 등
   - 보이스피싱 예방 주간 팁 (카드뉴스 형태)
   - 월간 성취 리포트 ("이번 달 3가지 배우셨어요!")
   - 반복 요청 감지 → 자동 가이드 추천

4. AI 고도화
   - 고객별 요청 패턴 학습 → 개인화 추천
   - 주기적 안부 메시지 (네이버 케어콜 벤치마크)
   - 신규 앱 업데이트 알림 ("배달의민족이 바뀌었어요, 달라진 점은...")
   - 예약 리마인더 ("내일 병원 예약 있으세요")

5. 안심 센터 (보안)
   - 실시간 의심 문자/전화 판별
   - 자녀에게 즉시 알림
   - 보이스피싱 신고 대행
   - 주간 보안 리포트

⛔ 2차에서 안 하는 것:
   - O2O 방문 케어
   - B2B 기업 복지
   - 커뮤니티 기능
   - 다국어 지원

💬 코멘트:
   Candoo Tech의 핵심 교훈 — "앱이 아닌 전화가 시니어의 진짜 진입점".
   전화 AI를 추가하면 스마트폰 자체가 어려운 고객까지 커버.
   PWA는 "홈 화면 추가"로 앱처럼 쓸 수 있어 설치 부담 최소화.
   네이버 케어콜의 "기억하기" 기능을 AI에 적용하면 만족도 90%+ 달성 가능.


====================================
3차 개발 — O2O 확장 + B2B + 수익화
"방문도 되고, 기업 복지도 되고, 돈이 된다"
====================================

목표: 오프라인 방문 케어 + B2B 기업 복지 + 커뮤니티 + 글로벌 준비

만들 것:
1. O2O 방문 케어
   - 방문 예약 시스템 (날짜/시간/주소/요청사항)
   - 지역별 상담원 매칭 (디스패치 시스템)
   - 상담원 앱: 일정 관리, 네비게이션, 완료 보고
   - 방문 후 만족도 평가
   - 정기 방문 구독 (월 2회/4회)
   - 벤치마크: Papa "주문형 손주" + Geek Squad 방문 서비스

2. B2B 기업 복지 대시보드
   - 기업 관리자: 임직원 부모님 일괄 등록
   - 기업별 사용 통계/리포트
   - 기업 맞춤 요금 (인당 15,000원/월)
   - 벤치마크: Papa 보험사 B2B2C 모델

3. 파트너 연동 (AARP 허브 모델)
   - 키오스크 업체 연동 (QR코드 → 즉시 도움)
   - 통신사 시니어 요금제 번들
   - 보험사 고객 혜택 연동
   - 복지관/지자체 위탁 운영

4. 커뮤니티
   - 또래 시니어 소통 공간
   - "나도 해냈어요" 성취 공유
   - 지역별 오프라인 모임 연결

5. 글로벌 준비
   - 다국어 지원 (일본어 우선 — 고령화율 29% 세계 1위)
   - 현지화 AI 모델
   - 글로벌 파트너십 (일본 NTT, AARP 등)

💬 코멘트:

   O2O 방문 케어는 오프라인 접근 채널로서 3차에서 본격 구현.
```

🛠️ **수정 제안**: 1차 MVP에서 카카오 채널 API 기능 범위를 확인하는 기술 스파이크(탐색 개발)를 첫 주에 진행할 것.

🔍 **발견 2**: "AI가 직접 맥도날드 주문을 처리"하려면 맥도날드 API 연동이 필요한데, 공개 API가 없을 수 있음.
🛠️ **수정 제안**: MVP에서는 AI가 "주문 방법 안내"까지만 하고, 직접 주문은 상담원이 수동 처리. 이후 배달의민족/요기요 API 연동으로 자동화.

🔍 **발견 3**: 7일 무료 체험 → 자동 전환 시 소비자 불만 가능성 (의도치 않은 결제).
🛠️ **수정 제안**: 전환 48시간 전 + 24시간 전 2회 안내 + 원클릭 해지 버튼 필수.

🔍 **발견 4**: 충전제 모델에서 건당 단가 책정이 실제 운영 비용과 맞지 않을 수 있음.
🛠️ **수정 제안**: MVP 기간 동안 실제 처리 건당 비용을 측정하여 단가 조정. 초기에는 보수적으로 책정 후 데이터 기반 최적화.
