# 도메인: 가족 (Family)

## 정의
자녀가 부모님 구독을 선물하고, 부모님의 활동/성취를 확인하며, 긴급 알림을 받는 영역

## 핵심 책임
- 부모님 연결 (초대/수락)
- 부모님 활동 요약 조회 (건수만, 내용 비공개)
- 성취 알림 ("엄마가 KTX 예매를 혼자 하셨어요!")
- 보이스피싱 의심 시 긴급 알림
- 구독 선물 결제 흐름

## 책임지지 않는 것
- 부모님 대화 내용 열람 (프라이버시 보호)
- AI 응답 생성 (채팅 도메인 담당)
- 결제 PG 연동 (결제 도메인 담당)

## 연관 도메인
- 채팅 (Chat): 부모님 활동 건수 제공, 보이스피싱 알림 트리거
- 결제 (Payment): 구독 선물 결제 처리
- 인증 (Auth): 가족 가입/로그인 (카카오 소셜)

## 포함된 엔티티
- FamilyLink: 자녀-부모 연결 관계
- ActivitySummary: 부모님 활동 요약 (건수, 카테고리)

## 포함된 유스케이스
- gift-subscription: 부모님께 구독 선물하기
- view-activity: 부모님 활동 요약 조회
