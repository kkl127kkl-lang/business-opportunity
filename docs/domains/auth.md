# 도메인: 인증 (Auth)

## 정의
사용자 가입/로그인/권한 관리를 처리하는 영역. Supabase Auth 기반.

## 핵심 책임
- 가족(자녀) 카카오 소셜 로그인
- 상담원/관리자 이메일 로그인
- 시니어 카카오톡 채널 연동 (별도 가입 불필요)
- 역할 기반 접근 제어 (시니어/가족/상담원/관리자)

## 책임지지 않는 것
- 카카오톡 메시지 처리 (채팅 도메인 담당)
- 결제 (결제 도메인 담당)

## 연관 도메인
- 채팅 (Chat): 시니어 인증 상태 확인
- 가족 (Family): 가족 로그인/권한
- 상담 (Counseling): 상담원 로그인/권한

## 포함된 엔티티
- User: 사용자 (시니어/가족/상담원/관리자)
- Session: 인증 세션

## 포함된 유스케이스
- login: 로그인 (카카오 소셜 / 이메일)
- register: 가족 회원가입
