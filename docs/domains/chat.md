# 도메인: 채팅 (Chat)

## 정의
시니어가 카카오톡으로 디지털 문제를 요청하고, AI가 해결하거나 상담원에게 넘기는 핵심 서비스 영역

## 핵심 책임
- 카카오톡 채널을 통한 메시지 수신/발신
- Claude API를 사용한 AI 자동 응답
- 17개 카테고리 요청 분류
- 대화 기억 (이전 요청 맥락 유지)
- 보이스피싱 의심 링크/문자 판별
- AI가 처리 못 하는 요청 → 상담원 에스컬레이션

## 책임지지 않는 것
- 결제 처리 (결제 도메인 담당)
- 가족 알림 발송 (가족 도메인 담당)

## 연관 도메인
- 상담 (Counseling): AI가 못 풀면 상담원에게 넘김
- 가족 (Family): 보이스피싱 감지 시 가족에게 긴급 알림
- 인증 (Auth): 시니어 본인 확인

## 포함된 엔티티
- ChatSession: 대화 세션 (시니어 1명의 연속 대화)
- ChatMessage: 개별 메시지 (요청/응답)

## 포함된 유스케이스
- send-message: 시니어가 카톡으로 요청 보내기
- ai-respond: AI가 요청을 분석하고 해결
- escalate: AI가 못 풀면 상담원에게 넘기기
- detect-phishing: 보이스피싱 의심 판별
