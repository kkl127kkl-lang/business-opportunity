# 도메인: 결제 (Payment)

## 정의
구독 플랜 선택, 충전제 결제, 자녀→부모 선물 구독 등 모든 결제/과금을 처리하는 영역

## 핵심 책임
- 3개 구독 플랜 관리 (라이트/스탠다드/패밀리)
- 충전제 결제 (10,000원 선불 충전, 건당 차감)
- 7일 무료 체험 → 자동 전환
- 토스페이먼츠 PG 연동 (카카오페이 + 카드)
- 자녀→부모 선물 구독 흐름
- 구독 해지/변경

## 책임지지 않는 것
- 서비스 이용 (채팅/상담 도메인 담당)
- 가족 연결 (가족 도메인 담당)

## 연관 도메인
- 가족 (Family): 선물 구독 결제 트리거
- 인증 (Auth): 결제자 본인 확인

## 포함된 엔티티
- Subscription: 구독 정보 (플랜, 상태, 기간)
- Payment: 결제 내역
- Credit: 충전 잔액

## 포함된 유스케이스
- subscribe: 구독 플랜 결제
- charge-credit: 충전제 결제
- cancel-subscription: 구독 해지
