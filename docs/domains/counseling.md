# 도메인: 상담 (Counseling)

## 정의
AI가 해결하지 못한 요청을 인간 상담원이 처리하는 영역. 관리자 대시보드를 통해 에스컬레이션된 요청을 관리.

## 핵심 책임
- 에스컬레이션된 요청 큐 관리
- 상담원 배정 및 상태 관리
- 고객 대화 히스토리 열람
- 카톡 채널을 통한 상담원 직접 응답
- 요청 유형/처리 시간/만족도 통계

## 책임지지 않는 것
- AI 자동 응답 (채팅 도메인 담당)
- 결제/구독 관리 (결제 도메인 담당)

## 연관 도메인
- 채팅 (Chat): AI에서 에스컬레이션된 요청 수신
- 인증 (Auth): 상담원 로그인/권한 관리

## 포함된 엔티티
- Ticket: 상담 요청 건 (상태: 대기/진행중/완료)
- Agent: 상담원 정보

## 포함된 유스케이스
- handle-ticket: 상담원이 요청 처리
- view-dashboard: 상담원 대시보드 조회
